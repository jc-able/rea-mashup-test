# Controls

These are the documented mappings in the project snapshot. They are not a claim that every action or controller was independently tested.

## Wrestling Smash — wrestlers in the platform fighter

| Action | Player 1 keyboard |
|---|---|
| Move | WASD |
| Walk / tilt modifier | Hold Left Shift |
| Attack | J |
| Special | K |
| Jump | I or Space; up also jumps |
| Shield | L |
| Grab | U |
| Taunt | O |
| Pause | Enter |
| Toggle Smash / SvR wrestler animations | F4 |
| Hitbox and animation provenance overlay | F1 |
| Model / debug skeleton toggle | F2 |
| Camera toggle | F3 |
| Fullscreen | F11 |
| Quit-to-menu prompt | Esc |

The animation toggle changes presentation. Selected recorded simulation values matched in bounded checks; complete original-game fidelity and universal animation parity were not established.

## Smash Wrestling — Smash cast in wrestling arenas

Use Exhibition for player versus CPU or CPU versus CPU to watch. Select fighters, arena, difficulty and whether entrances play.

| Action | Keyboard |
|---|---|
| Move | WASD / arrow keys |
| Run | Hold Shift |
| Strike | J; hold for strong strike |
| Grapple | K + direction; repeat to throw |
| Submission | E |
| Release a hold | Space |
| Irish whip / pin a downed opponent | L |
| Climb corner / enter or exit ring | Space near the relevant position |
| Reversal | I, timed to impact |
| Signature / finisher | O when ready |
| Taunt | T |
| Escape hold / submission / pin | Mash J, K, L and Space |
| Pause | Esc or P |
| Controls overlay | Hold F1 |
| Skip an entrance | Enter or Esc |

Q / RB position change is mapped but unimplemented in this snapshot. Contact, camera and UI issues remain. Gamepad mappings exist in the source; physical gamepad behavior has not been comprehensively verified.
